{# Инструкция установки для iPhone/iPad: Safari не даёт сайтам показывать окно установки (логика — static/js/pwa.js) #}
Установка на iPhone и iPad
  1. Нажмите «Поделиться» — в Safari внизу экрана, в Chrome справа в адресной строке.
  2. Выберите «На экран Домой». Если пункта не видно, прокрутите список действий вниз.
  3. Нажмите «Добавить».

Иконка Tracker Workout появится на экране, а сайт будет открываться как приложение — без адресной строки браузера.

{# Android в браузерах, которые вместо установки кладут на экран ярлык (Яндекс, Xiaomi, Firefox…) #}
Установка на Android

Этот браузер добавляет на экран обычный ярлык — сайт откроется внутри браузера, с адресной строкой. Приложение в отдельном окне устанавливает Chrome:

  1. Откройте сайт в Chrome — кнопкой ниже или вручную: tracker-workout.ru.
  2. В Chrome нажмите «Установить приложение» в меню сайта или в меню браузера ⋮.
  3. На Xiaomi, Redmi и POCO, если после установки иконка не появилась: Настройки → Приложения → Chrome → Другие разрешения → «Ярлыки на рабочем столе» → Разрешить, затем установите ещё раз.
Открыть в Chrome

Старый ярлык браузера с рабочего стола можно удалить.
