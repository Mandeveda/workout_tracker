## Этап A. Подтверждение почты при регистрации

Сейчас проверяется только формат адреса (план исправлений 2.4). Нужно убедиться, что почта настоящая и принадлежит пользователю.

**Решения:**
- Подтверждение ссылкой из письма; войти и тренироваться можно сразу, до подтверждения — напоминание. Функции, где важна настоящая почта (заявка тренеру — этап D), будут требовать подтверждения.
- Подтверждать должны все, включая уже зарегистрированных.
- Почту можно сменить (ошибка при регистрации): новый адрес применяется только после подтверждения ссылкой, отправленной на него; до этого действует старый.
- На подтверждение — 30 дней (у новых — с регистрации, у существующих — с момента обновления). Напоминание со счётчиком: «осталось N дней, иначе аккаунт может быть удалён».
- Автоматически ничего не удаляется: админ видит, у кого срок истёк (пометка и фильтр), и сам решает — удалить (этап B) или заблокировать.

- [ ] **A.1** Модель: дата подтверждения, срок подтверждения, ожидающий подтверждения новый адрес; миграция (существующим — срок 30 дней с обновления)
- [ ] **A.2** Письмо со ссылкой после регистрации; подписанная ссылка на 3 дня, без отдельной таблицы
- [ ] **A.3** Напоминание со счётчиком дней на всех страницах; повторная отправка (с лимитом)
- [ ] **A.4** Смена почты в профиле через подтверждение нового адреса
- [ ] **A.5** Админка: пометки «не подтверждена / срок истёк», фильтр
- [ ] **A.6** Тесты

## Этап B. Удаление пользователей и шаблонов администратором

Сейчас нельзя удалить пользователя, у которого есть шаблоны или тренировки, и шаблон, по которому была тренировка или есть расписание. Связи в базе: пользователь ← упражнения каталога (автор), шаблоны, тренировки, расписание, токены сброса пароля; шаблон ← упражнения шаблона, расписание, тренировки.

**Решения:**
- Пользователь удаляется со всеми данными (шаблоны, расписание, тренировки, замеры); перед удалением — перечень того, что пропадёт, и ввод имени для подтверждения.
- Шаблон с историей можно удалить: будущие тренировки по нему убираются из расписания, проведённые остаются в истории и статистике с сохранённым названием.

- [ ] **B.1** Удаление пользователя со всеми данными (с явным подтверждением)
- [ ] **B.2** Упражнения каталога, созданные удаляемым пользователем (эксперт)
- [ ] **B.3** Удаление шаблона, по которому есть история / расписание
- [ ] **B.4** Тесты
